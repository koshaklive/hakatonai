Извлеки из реплики пользователя значения полей документа по JSON-схеме модуля.
Схема полей:
{{schema}}

Правила:
1. В "fields" ВСЕГДА перечисли ВСЕ поля схемы. Нет данных — null, и добавь имя поля в "missing". Заполненное поле в "missing" не попадает.
2. Не выдумывай значения. Но то, что названо явно или очевидно из фразы (например, «докладная директору» → адресат «директор»), извлекай.
3. Даты — ДД.ММ.ГГГГ, если год известен. «Срочно» → true, «не срочно» → false, не упомянуто → null.
Верни только JSON: {"fields": {...}, "missing": [str]}
